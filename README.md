### ⭐ Featured projects

**[RegLens](https://github.com/RB6339/reglens)**: a RAG assistant for RBI Master Directions that answers with the exact paragraph and page.
Paragraph-level chunking that follows RBI numbering, hybrid retrieval (BM25 + embeddings with reciprocal rank fusion), grounded LLM answers with citation checks and refusals, a labelled evaluation set, FastAPI, Docker and CI.
**[▶ Live demo on Hugging Face](https://huggingface.co/spaces/RB6339/reglens)**

`RAG` `Hybrid search` `LLM` `Evaluation` `FastAPI` `Docker`

**[JobScout MCP](https://github.com/RB6339/jobscout-mcp)**: an MCP server with a LangGraph agent that analyses the AI/ML job market.
It searches jobs, ranks the most requested skills and computes your skill gap per job. Comes with FastAPI, Docker, GitHub Actions CI and end-to-end MCP protocol tests.
Plugs straight into any MCP client (Cursor, VS Code, ...).

`MCP` `LangGraph` `LLM agents` `FastAPI` `Docker` `pytest`
